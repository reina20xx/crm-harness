# CRM Harness — Zero-Input AI Sales CRM & MEDDIC Deal Engine

**CRM Harness** replaces bloated per-seat legacy CRM/SFA tools (Salesforce / HubSpot / Senses) with a **¥0/month Cloudflare Workers + D1 + MCP** autonomous sales deal engine.

## Why "SaaS is Dead" for Traditional CRM
Sales reps hate manually filling out 30 form fields after every call, and companies pay ¥18,000–¥36,000/user/month for a glorified CRUD database. **CRM Harness** eliminates manual data entry: paste raw meeting notes or call via MCP, and AI structures MEDDIC, updates win probability, flags stalled deals, and drafts executive follow-up emails in 0 seconds.

## Quick Start
```bash
git clone https://github.com/reina20xx/crm-harness.git
cd crm-harness
npm install
npm run dev
```
Open `http://localhost:8801` to use the interactive Zero-Input MEDDIC Dashboard.
